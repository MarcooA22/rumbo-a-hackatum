# Rumbo a hackaTUM

Colecta en pesos de Marco Amado. Sitio estático para GitHub Pages.

Editar data.json para registrar aportes confirmados: receivedARS, receivedEquivalentUSD y updatedAt (ISO 8601). La meta es USD 1500 equivalentes; no hay conexión bancaria. Un valor null indica que todavía no se cargó un corte: el sitio muestra 0% registrado. La página consulta el archivo cada minuto.

Publicación: rama main, carpeta raíz. Sin dependencias ni build. El plazo toma fin del 9 de noviembre de 2026 en Múnich (CET), equivalente a 19:59:59 de Argentina.
